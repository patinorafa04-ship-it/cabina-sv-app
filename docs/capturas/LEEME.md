# Capturas de la app

Para reemplazar una captura: tómala con el teléfono **en horizontal** (botón de encendido + bajar volumen) y guárdala aquí con este nombre exacto. La página y el README las muestran solas.

| Archivo | Qué mostrar |
|---|---|
| `01-inicio.jpg` | El inicio con música sonando, el mapa cargado y el GPS con señal (de día, tema automático o claro). |
| `02-navegacion.jpg` | Una ruta en curso: la flecha de giro arriba, el tiempo de llegada abajo y la velocidad. |
| `03-musica.jpg` | Música > Carpetas, o una carpeta abierta con sus canciones y carátulas. |
| `04-paises-sin-internet.jpg` | Con el modo avión activado, "¿A dónde vamos?" con resultados (por ejemplo "metrocentro"). |
| `05-radio.jpg` | La lista de emisoras o una emisora sonando. |
| `06-ajustes.jpg` | Ajustes > Apariencia (tema y colores) o Navegación (países sin internet). |

Consejos:
- Que no se vean datos personales: nombres de contactos, notificaciones privadas o tu casa en el mapa.
- Mejor sin notificaciones en la barra (activa "No molestar" un momento).
- Pásamelas por aquí y yo las recorto y optimizo si hace falta.
